⭐ Featured Project
CompScope
Compensation intelligence for comparing companies, roles, career levels, locations, and total compensation.
CompScope is my current flagship full-stack project.
The idea is simple:
```text
Company + Role + Level + Location
                +
       Base + Stock + Bonus
                ↓
       Total Compensation
```
Instead of treating compensation as a single number, CompScope explores how role, career level, location, and compensation components affect comparisons.
What I built
Compensation explorer
Company rankings
Compensation analytics
Role-level analysis
Location-level analysis
Career-level benchmarking
Compensation comparison
Data visualization
Search, filtering & sorting
Pagination
CSV export
Zod validation
Data normalization
Duplicate detection
Server-side compensation calculation
PostgreSQL persistence
Automated testing
Production deployment
